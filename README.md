# Task Management Dashboard

A simple task management dashboard built with React, Vite and plain CSS.

## Features

- Add, view, edit and delete tasks
- Set task priority, due date and status
- Search tasks by title
- Filter by status and priority together
- Sort tasks by due date
- Summary counts update when tasks change
- Saves tasks in browser LocalStorage
- Responsive layout for desktop, tablet and mobile

## Run locally

1. Install Node.js.
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown in the terminal.

No backend or database is required. Tasks are stored in the browser's LocalStorage.
